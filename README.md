# ZESTMOK (오목)

전 발로란트 프로게이머, 현 제스트아카데미를 운영하고있는 발로란트 소바 권위자 ZEST 내 친구를 기념하기 위한 오목 게임입니다.
브라우저에서 즐기는 오목 게임. 15×15 판, 한국식 규칙(흑 쌍삼·장목 금지).

- **한국식 규칙 (모든 모드 공통)** — 흑은 쌍삼(3-3)·장목(6목 이상)을 둘 수 없음(4-4와 정확히 5목은 허용), 백은 제한 없음. 금수 자리를 누르면 착수되지 않고 안내가 뜸. 팀전은 방장이, 온라인은 받는 쪽이 한 번 더 검증
- **AI 대전** — 쉬움 / 보통 / 어려움 / æ 원준 (결과 화면에 "AI 대전 · 난이도" 표시). 사람·AI 모두 위 규칙을 따름. 결과 화면 [다시 하기] = 같은 난이도·시간으로 돌 색 선택 창("다시 하기 · 난이도 · 시간" 제목, 여기서 바꿀 수도 있음), 방에서는 방장이 누르면 모두 로비로(팀 이동 가능)
- **대국 방식** — 모드 선택 후 [일반전 / 속기전(new!)]. 일반전: 시간 제한 없음·5분·10분 중 선택, 다 쓰면 초읽기 30초×3회. 속기전: 한 수 5초·10초, 넘기면 즉시 패배. AI 대전은 내 시간만 계산, 방은 방장이 정한 규칙을 참가자도 따름
- **방 만들기** (구 팀전, 1:1 온라인 대전 통합) — 최대 4명(1:1, 2:2, 3:1 등). 방장이 팀을 골라 방을 만들고, 참가자는 로비에서 팀 선택. 팀원이 나가도 계속 진행, 한 팀 전원이 30초 넘게 이탈하면 패배. 방장이 나가면 다음 접속자가 방장 승계
- **무승부 제안 · 항복** — [무승부 제안]은 차례와 상관없이 언제든, [항복](확인 창)도 언제든. 두 버튼은 항상 보이고 못 쓸 때는 비활성 + 이유 안내(대국 없음 / 투표 중 / AI 생각 중 / 기회 소진). 무승부 제안은 한 판에 한 사람당 2번(다 쓰면 버튼은 남고 비활성), 항복은 횟수 제한 없음. AI 대전: AI는 5칸 줄에 자기 돌 3개 이상 들어갈 자리가 없으면(`bestWindow ≤ 2`) 받아들임(보스도 같음), 항복은 AI 승리로 학습. 방: 무승부는 제안자 빼고 접속 중인 전원(양 팀)이 동시에 동의해야 성립, 항복은 접속 중인 내 팀원 전원 동의(혼자면 확인 창만). 거절 1명 또는 20초 무응답이면 취소되고 판 아래에 "○○님이 거절했습니다 — 게임이 계속됩니다!" 같은 알림, 진행 중에는 왼쪽 패널(모바일은 판 바로 위)의 새 게임/무승부 제안/항복 버튼 자리가 투표 칸("○○님의 무승부 제안 · 동의 n/m (18초)" + 동의/거절)으로 바뀌고, 끝나면 버튼이 돌아옴. 투표가 판을 가리지 않음. 결과 화면에 항복 / 합의 무승부 표시
- **더 이상 둘 수 없음 안내** — 양쪽 모두 상대 돌 없는 5칸 줄이 하나도 없으면 판 아래에 "더 이상 둘 수가 없습니다" 표시 + 무승부 버튼 강조(대국은 계속, 판이 가득 차면 기존처럼 무승부). 흑 금수는 고려하지 않음(필요조건)
- **다크/라이트 테마** — 헤더 오른쪽 위 토글. 기본은 OS 설정(`prefers-color-scheme`), 선택은 `zestmok-theme`에 저장하고 `<head>` 스크립트가 첫 화면 전에 적용(깜빡임 없음). 배경·패널·버튼·모달은 무채색 + 진초록 포인트 하나(`--accent`). 판(나무색)과 돌은 테마와 무관하게 그대로
- **글꼴 Galmuri11** (OFL 1.1, `vendor/fonts/`에 자체 호스팅) — 판 좌표(캔버스)·패널·모달·안내 전부. 글자 크기는 12/24/36px만 사용
- **Google 로그인 · 사진 돌** — 헤더의 프로필 메뉴: Google 로그인(공식 버튼, 메뉴를 처음 열 때만 GIS 로드), 사진 올리기, 사진 지우기(올린 사진이 있을 때), 다른 사람 사진 숨기기. **기본 돌은 항상 ZEST 사진**(`img/stone-black.jpg`·`stone-white.jpg`)이고, 내가 사진을 정했을 때만 CSS 변수 `--stone-black-img`/`--stone-white-img`가 그 사진으로 덮어씁니다(변수를 지우면 ZEST 사진으로 복귀: 사진 지우기·로그아웃·남의 사진 숨기기). AI 대전은 내 색에만 내 사진(AI 쪽은 ZEST 사진, 보스는 원준 사진). 방은 팀 대표(팀 첫 입장자) 사진을 쓰고 방장이 참가자 사진을 "사진 끄기"로 끌 수 있음. 설계: [`docs/profile-stones.md`](docs/profile-stones.md)
- 상대(AI) 차례에 누른 탭은 무시: AI가 생각하는 동안 눌린 탭이 내 차례가 되자마자 착수되던 문제를 막음(내 차례 시작 0.2초 안의 탭도 무시). 끝난 판의 결과 창을 닫은 뒤 판을 탭하면 돌 위에 둔 순서 번호를 보여주고, 다시 탭하면 숨김(안내 없는 숨은 기능, 방에서는 방장의 순서 기록을 받음)
- 모바일 터치, 키보드 조작(방향키 + Enter/Space), 스크린리더 안내 지원. 모바일 상단: 왼쪽에 두 플레이어(돌 사진·닉네임) 세로 배치, 오른쪽에 전적 + 전적 초기화, 그 아래 새 게임 / 무승부 제안 / 항복

## AI 난이도

| 난이도 | 수준 | 방식 |
|---|---|---|
| 쉬움 | 입문 | 1수 앞만 보고, 상대 5목을 절반만 막음 |
| 보통 | 중급 | 3수 탐색, 열린 3·4 대응 |
| 어려움 | 상급 | 4수 탐색(후보 12, 최대 0.8초) + 연속 4 강제승 탐색(공격·수비) |
| æ 원준 | 보스 | 초반 정석표(Rapfi로 만든 `ai-open.js`) + 패턴표 평가(Rapfi에 맞춘 점수표) + 10수 탐색(최대 3.5초, 루트 후보 24·내부 16) + 4연속·열린3 강제승(VCF/VCT) 탐색, 전치표로 같은 국면 중복 계산 제거 |

서열 측정(`node tests/duel.js A B 쌍수`, 고정 깊이·색 교대·무작위 오프닝, 순차 실행): 쉬움 대 보통 24:76 · 보통 대 어려움 36:64 · 어려움 대 보스 23:77(40판).

æ 원준 난이도에서는 AI 돌이 원준 사진으로 바뀌고, 지면 결과 화면에 사진과 "패배"가 표시됩니다.

원준 강화:
- **초반 정석표**: 보스가 흑(가운데 첫 수)·백일 때 자주 나오는 초반 국면(약 12수까지)에서 Rapfi(로컬 엔진, 사이트에 없음)가 200만 노드로 찾은 최선수를 둡니다. 8가지 회전·대칭과 평행이동까지 같은 국면으로 알아봅니다(돌과 수가 판 가장자리 2칸 안이면 쓰지 않음). 흑 금수 자리, 전에 졌던 수(학습 `avoid`)는 두지 않고 탐색으로 넘어갑니다. `ai-open.js`, 보스 단계에서만 지연 로드.
- **패턴표 평가 (보스만)**: 빈 칸마다 4방향 줄 모양(열린/닫힌 1~4, 5, 장목 11종)을 표에서 읽고, 돌을 놓을 때 그 줄의 칸만 고칩니다(증분). 평가 = 칸마다 4방향 모양 조합(1001가지)의 점수 합 + 위협 지표, 점수는 Rapfi 승률에 맞춘 값(`tools/engine/fit-eval.js`). 예전 5칸 구간 평가보다 노드당 약 4배 빠름. 보스는 상대가 흑일 때도 흑 금수를 압니다.
- **후보 고르기 (보스만)**: 칸 점수(맞춘 표)로 모든 근처 칸을 줄 세운 뒤, 3수 얕은 탐색 점수로 다시 줄 세워 상위 24개(+ 방어 자리)만 본 탐색에 넣습니다. 내부 노드는 표 점수 상위 12개.
- **공격/방어 우선순위 (매 수 다시 판단)**: ① 바로 이길 수 있으면 둠 → ② 상대 5목 막기 → ③ 내 4연속 강제승 → ④ 상대 4연속 강제승 차단 → ⑤ 내가 열린 4를 만들 수 있으면 공격 우선(방어 보너스 없음) → ⑥ 아니면 상대의 열린 4 자리(+4000)와 요주 자리(+2500)에 방어 보너스를 얹어 탐색.
- **33/44/43/6목 전부 경계**: 매 수마다 상대가 3-3 / 4-4 / 4-3 / 6목을 만들 수 있는 자리를 **모두** 찾아 탐색 후보에 넣고 먼저 차지하려 합니다. 흑은 3-3·6목이 금수라 흑 상대로는 4-4·4-3만 해당.
- **VCT 탐색 (위협 공간 탐색)**: 4연속(VCF)뿐 아니라 열린 3까지 써서 이어지는 강제 공격을 공수 양쪽에서 탐색합니다 (최대 6수 깊이, 호출당 시간 제한). 사람의 3-3·4-3 연타 같은 수를 미리 읽고 막고, 보스에게 강제승이 있으면 바로 둡니다.
- **상 엎기**: 질 것이 확실해지면 판을 엎습니다(지진 → 돌이 흩날림 → 판이 뒤집혔다가 재조립). 한 대결당 1회, 전적 그대로. 엎은 판은 AI 패배 1판으로 학습에 기록되고(애니메이션 도중 나가도 기록, 회전 4방향 포함), 재시작은 항상 AI 선공입니다 (원래 AI가 백이었어도 엎은 뒤에는 AI=흑, 사람=백으로 바뀜). 엎을 때 화난 원준 사진이 뜨고, 엎은 뒤 그 한 판 동안만 AI 돌이 그 사진으로 바뀝니다.

### 학습 (쉬움 제외, 브라우저별)

AI는 대국 결과를 이 브라우저(`localStorage`, 난이도별로 따로)에 기억하고 다음 판에 반영합니다.

- **같은 수 반복 방지** — 사람이 이기면 AI의 마지막 수들(연승할수록 더 앞쪽까지)을 해당 국면에서 다시 두지 않습니다. 같은 수순으로 두어도 AI가 같은 수로 지지 않습니다.
- **상대 수 예측** — 국면별로 사람이 둔 수와 그 판의 승패를 기억해, 이미 이겼던 응수로 이어지는 수는 피합니다.
- **맞춤 난이도** — 사람이 연승하면(최대 3) 탐색 깊이·후보 수가 늘어납니다(깊이 최대 +2, 후보 최대 +6). 제한 시간은 그대로입니다. AI가 이기면 연승 기록이 초기화됩니다.
- 같은 국면(돌 배치와 차례 일치)과 그 판을 **90°·180°·270° 돌린 국면**까지 함께 기억합니다(돌린 판에서 같은 수를 둬도 알아봄, 좌우 대칭은 미포함). 최대 4,000개 국면까지 저장하고 오래된 것부터 지웁니다. 브라우저 데이터를 지우면 초기화됩니다.

### 보스 공용 학습 (모든 방문자)

보스 대국이 끝나면 기보(수순만, 개인정보 없음)를 구글 시트로 익명 전송합니다(페이지 하단에 작게 안내). 모은 기보를 `tools/build-book.js`로 검증해 `ai-book.js`(공용 학습)로 만들고 배포하면, 보스를 고른 모든 브라우저가 자기 학습과 함께 씁니다. 설정·갱신 방법: [`docs/boss-book.md`](docs/boss-book.md)

`node tests/ladder.js`로 난이도별 상대 전적을 측정할 수 있습니다(느림).

## 실행

빌드 과정이 없는 정적 사이트입니다. `index.html`을 바로 열거나 로컬 서버를 띄우면 됩니다.

```sh
npm run serve   # http://localhost:8080
```

## 온라인 대전 구조

- 서버 코드는 없습니다. 브라우저끼리 WebRTC(PeerJS 1.5.4, `vendor/`)로 직접 통신하고, 연결 중개만 PeerJS 공용 브로커(`0.peerjs.com`)를 씁니다.
- 방 만들기 → 6자리 코드 공유 → 참가자가 코드 입력. 최대 4명(1:1 ~ 3:1), 방장(호스트)이 판의 기준입니다.
- 참가자는 수만 보내고, 방장이 차례·범위·빈 칸·금수·시간을 검증한 뒤 전체 상태(스냅샷)를 모두에게 보냅니다. 시계 상태도 스냅샷에 포함됩니다.
- 방장이 나가면 다음 접속자(입장 순서)가 같은 방 코드를 다시 열어 방장을 승계합니다. 한 팀 전원이 30초 넘게 이탈하면 그 팀 패배.
- 자세한 설계: [`docs/team-mode.md`](docs/team-mode.md)

### 연결이 안 되는 경우 (TURN)

같은 망이나 일반 가정용 망은 STUN만으로 연결됩니다. 모바일 데이터, 회사·학교망 등에서 연결이 안 되면 `index.html`의 `ICE_SERVERS`에 TURN 서버를 추가하세요.

```js
{urls: 'turn:YOUR_TURN_HOST:443?transport=tcp', username: 'USER', credential: 'PASS'},
```

정적 페이지이므로 이 값은 공개됩니다. 사용 한도가 있는 무료 TURN 계정을 쓰는 것을 권장합니다.

## 테스트

```sh
npm test                    # AI · 방/시계 · 프로필 단위 테스트 (Node만 필요)
npm i && npx playwright install chromium
npm run test:ui             # 브라우저 UI/키보드/모바일 테스트 (로컬)
npm run test:team           # 4개 브라우저 방 만들기 E2E + 1:1 속기전 (인터넷 필요)
```

AI 세기 측정 (수동, 느림):

```sh
node tests/duel.js boss hard 20          # 흑백 교대 40판, 승률만 (약 45분)
node tests/duel-record.js 20 1 games.json  # 같은 40판 + 기보 저장
node tests/analyze-losses.js games.json    # 진 판별 원인 분석 (판당 수 분)
B_AI=/path/old-ai.js node tests/duel.js boss boss 20   # 새 보스(A) vs 옛 ai.js 사본의 보스(B)
```

보스 v2 도구 (로컬 Rapfi 필요, `RAPFI=/path/pbrain-rapfi`, 자세한 것은 [`docs/boss-ai-v2.md`](docs/boss-ai-v2.md)):

```sh
node tools/engine/build-opening.js /path/opening.jsonl        # 정석표 → ai-open.js (약 2시간, 이어서 하기 가능)

node tools/engine/fit-eval.js --write /path/labels*.jsonl     # 패턴 점수표 맞춤 → ai.js TAB (엔진 불필요)
node tools/engine/selfplay.js 20 1 200000 sp.jsonl            # 보스 vs Rapfi + 채점 (BOSS_AI=옛 사본 가능)

node tools/engine/same-move.js sp.jsonl                       # 보스를 채점 국면에 다시 둬서 Rapfi와 같은 수 % + 한 수 시간
node tools/engine/speed.js /path/old-ai.js 30 1000 sp.jsonl   # 노드/초 비교
```
